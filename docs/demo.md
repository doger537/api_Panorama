# Демонстрация MVP

Используйте новый аккаунт CLI и новую карту по README. Покажите импорт/рисование, изменение POI, явные проходы, загрузку сферы и настоящую серию съёмки. В inspector привяжите сферы к разным узлам; направленные переходы нужны отдельно для каждого направления маршрута.

Публичную карту откройте в независимом браузерном контексте. Измените описание, сохраните и дождитесь live update без смены URL. Проверьте 412 двумя вкладками и unpublish с отзывом доступа к медиа. Покажите ошибку/отмену job и самостоятельную загрузку готовой сферы.

`npm --prefix frontend run test:e2e` воспроизводит браузерный сценарий в изолированном окружении; Hugin fixtures проверяются backend suite. Физическая камера по HTTPS требует отдельной приёмки на телефоне. Синтетическая картинка в тесте прямого upload не считается успешной склейкой.
