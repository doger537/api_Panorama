# Серии для склейки

`backend/tests/fixtures/stitch/manifest.json` перечисляет 16 кадров series_01 и SHA-256. Это фотографии, предоставленные участником проекта с указанным в manifest разрешением на тестирование. Модель устройства и дата съёмки независимо не подтверждены; имена файлов содержат 2026-10-24. Приписывать EXIF/устройство/180° вертикального покрытия без измерения нельзя.

Наборы: series_01 (16 уникальных кадров), negative_duplicates (16 файлов/15 уникальных), negative_incomplete (8 файлов). Набора несвязанных локаций пока нет, он не учитывается в приёмке. API tests могут генерировать изображения отдельно.

Реальный pipeline тестируется в backend/tests/stitch/test_pipeline.py. Успех требует закрывающего шва и соседних соответствий, затем измеренного alpha coverage. Результат частичный по вертикали; метаданные проверяются относительно cropped height. Качество швов на физическом телефоне проверяется отдельно.
