# Приёмка TTKMap

## Границы проверки 24 октября 2026

Автоматические проверки используют Linux x86_64, Python 3.12 в Docker, Node 22 в build stage и Chromium Playwright. Камера в браузерном тесте — MediaStream из canvas с реальными fixture-фотографиями; JPEG encoder, IndexedDB, HTTP API, SQLite и Hugin/enblend настоящие. Это не съёмка физическим телефоном.

Результаты команд и исправлений: [audit-resolution.md](audit-resolution.md). Исторические числа в `Audit.md` относятся к старому коммиту.

## Оставшаяся физическая приёмка

Нужны iPhone/Safari и Android/Chrome с доступом к развёрнутому HTTPS-сервису. Эти испытания не выполнены в текущем окружении; модель телефона исходной fixture-серии неизвестна. Нельзя заполнять эту таблицу результатами Chromium или jsdom.

| Проверка | Устройство / ОС / браузер | Результат и измерения |
|---|---|---|
| Разрешение и отказ камеры, optional orientation | Не предоставлено | Не проверено |
| 16 разных кадров, preview, retake, поворот и возврат во вкладку | Не предоставлено | Не проверено |
| Потеря сети, reload pending frame, retry/cancel/new, получение результата | Не предоставлено | Не проверено |
| Три реальные серии из разных точек, визуальная оценка швов | Не предоставлено | Не проверено; в репозитории одна положительная серия |
| Touch выбор/перемещение, zoom и редактирование вершин | Не предоставлено | Не проверено |
| WebGL, ограниченный pitch, fullscreen и переходы | Не предоставлено | Не проверено |
| Внешний iframe с отключёнными third-party cookies | Не предоставлено | Не проверено на телефоне |
| Первый план/preview, live update, health во время upload, память worker | Не предоставлено | Измерить сеть, размер входов, p50/p95 и peak RSS |

Для каждой записи нужны дата, модель, версии ОС/браузера, URL/коммит, условия сети, шаги и фактический результат. Если шов неудовлетворителен, приложить входную серию с разрешением автора и описание артефакта. Linux-контейнер не подтверждает macOS, Windows или ARM64; для них нужен отдельный smoke сборки.

## Релиз

До релиза выполнить независимое review auth, данных, контрактов и worker по `AGENTS.md`, затем device acceptance. Статус задачи в manifest остаётся `in_progress` до merge. Пользователь отдельно разрешил push ветки и создание PR на GitHub без испытаний на физических устройствах; открытие PR не подтверждает device acceptance.
